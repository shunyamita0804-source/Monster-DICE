# PHASE 1 確定仕様（要点）

最終設計書のうち、実装で必ず守る点です。

## モードと遷移
- モードは TOWN（街）と RAISING（ファーム）の2つだけ
- 画面は所属モードを宣言する。モードが合わない画面へは移動できない（育成中に街へ戻る遷移は存在しない）
- TOWN → RAISING の入口は、市場購入・合体・特殊復元の3つだけ
  - 流れ：開始判定 → 名前設定（購入確定後はキャンセル不可、初期値は種族名）→ 確定（消費・個体生成・RAISING をまとめて1回で）→ オートセーブ → ファーム
- 育成終了は成功／失敗を分けた処理。失敗は PHASE 2 で確定（現在は仮処理）

## 牧場満杯
- 判定式：牧場の登録数 − 消費される親の数 < 20
- 市場購入・特殊復元は20体で止まる。合体は親2体が消えるので20体でも開始できる
- 判定の順番：満杯 → 所持金 → 確認。止まった時は何も消費しない
- 案内文：「ぽかぽか牧場がいっぱいです。合体などで空きを作ってください」

## 救済
- TOWN で街に入った時点で500G未満なら、500Gになるよう補填（ロード直後も対象）

## 解放
- ノビトン：育成成功数3以上で、次に市場に入った時に解放イベント。永久フラグ

## セーブ
- 手動3枠（セーブ1〜3）＋オート1枠
- 育成中の保存はファームから再開
- オートセーブ：モード切替時・購入時・週が進んだ時・施設から街に戻った時・解放時

## レスポンシブ
- 1080×1920 は基準座標。画面は9:16に固定しない
- UI倍率 = 安全領域に基準枠が収まる倍率。縦に余った高さは上揃えと下揃えの間に広がる
- 背景は 1080×2340。画面の上下を必ず覆い、中心を UI の基準枠と揃える
- スマホは左右を背景で埋める（基準枠の上下は各3%まで切れてよい）。iPad 等は左右をぼかしで補完
- 操作UIは Safe Area の内側。タップできる範囲は44pt以上
- 縦向き専用

## 市場カルーセル（ステップ6で実装）
- ループ式。左右どちらへスワイプしても循環する
- 下部にカード一覧は置かない。中央が最大で手前、左右が小さく奥
- 左右をタップすると中央へ、中央をタップすると詳細（未解放なら「まだ購入できません」）
- 重複表示を出さないため、各モンスターは「中央から最短の位置」に1体ずつだけ描く
  - 3体：中央と左右の3か所に1体ずつ。回り込む個体は奥を通って反対側へ移り、分身しない
  - 5体以上：スワイプ中だけ奥の2体目がフェードで見える
  - 2体：もう1体は直前にスワイプした方向の側に置く。1体：スワイプしない
- はじいた時に進むのは、3体以下なら1体まで（高速回転させない）。それ以上は最大で数の半分まで
- 未解放の表示：正式な立ち絵がある → シルエット＋？＋鍵 ／ デザインが無い → 台座に「？？？」＋鍵だけ（姿は作らない）
- 市場では技を見せない

## 素材
- 街・市場の完成図は基準画像。描かれた数値・文字はデータとして使わない
- パラメーター色：ライフ黄・ちから赤・かしこさ緑・命中ピンク・回避水色・丈夫さ青（data/theme.json が唯一の定義）
- ガウルは赤白の鳥型のみ（市場画像の赤い獣は不採用）
- アルトの顔は固定しない（枠は空で表示）。タイトル絵は現状を正式とし、画像ごと差し替え可能に
- 通貨は金貨アイコン＋G
- 博物館のピンは研究員完成まで施設アイコン
- 未完成の素材は、絵文字・白カード・作ったシルエットで埋めない
