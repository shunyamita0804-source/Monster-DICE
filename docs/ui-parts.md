# 共通UI部品（ステップ3）

開発用の「UI部品集」画面（起動時の既定画面）で、実際のゲームと同じ倍率で確認できます。
基盤チェックは `?dev=foundation` で開きます。

## デザイン言語（v3：明るいアイボリー基調の王道JRPG）

**方向転換の経緯**：v1は木を使いすぎて軽く安っぽく見え、v2は黒鉄・金属・メダリオンを使いすぎて重厚なダークファンタジー風になった。v3はその中間ではなく、「明るいアイボリーの紙」を基調に転換した。

**面の構成比の目安**：白70% + クリーム20% + 古紙感10%。真っ白なWebサイトにはしない。

**素材の使い分け**
| 素材 | 使う場所 |
|---|---|
| アイボリーの紙 | すべての基本面（パネル・ボタン・リスト・カード） |
| 細い焦げ茶の線 | すべての外枠（太い枠は禁止） |
| ごく細い真鍮の線 | 内側の縁取り、ボタン両端の小さな菱形 |
| 金（明るい） | 選択中と重要な決定だけ。囲うための色ではない |
| 木 | 見出し看板・施設名だけ |
| 能力色・分類色 | 細い縦線、ゲージの塗り、小さなタグ、下線。文字全体は染めない |
| 蔦の葉飾り | パネルの角に控えめに（重要パネルのみ） |

**装飾の考え方**：足し算ではなく引き算。「寂しいから金を足す」という判断はしない。上質さは余白・整列・文字階層・細い線で作る。

**文字の階層**：見出し＝濃い焦げ茶、本文＝濃い茶、補助＝薄い茶、重要数値＝濃く大きく、金文字＝タイトル・看板だけ。縁取りは背景の絵の上に直接置く文字だけ。

**能力の見せ方**：メダリオン／アイコンは廃止。「能力名の文字＋能力色の細い縦線」で識別する。ゲージは细く水平、両端は軽い丸め、鋲や剣先形はなし。

## 正式素材への差し替え方法
**アイコン・質感・装飾（ファイルを置き換えるだけ）**
1. 正式ファイルを assets/ の該当フォルダに置く（例：assets/ui/icon_gold.png）
2. data/assets.json の該当項目（例：`icon.gold`）の `path` を新しいファイルに、`status` を `official` にする

部品のコードは修正不要です。

**パネル・ボタンの1枚絵（9分割で伸縮）**
1. 画像を assets/ui/ に置く
2. data/assets.json の `ui.panel.wood` などに、次の値を書く
   - `path`：画像の場所
   - `status`：`official`
   - `slice`：四隅として切り分ける位置（例：`"60 60 60 60"`）
   - `width`：枠の太さ（rem、例：`4`）
3. 起動時に html に `has-ui-panel-wood` が付き、CSSで作った縁と影が消えて、画像表示に切り替わる（css/ui/skins-official.css）

## v4：5項目の調整（前回v3からの差分）

v3の「明るいアイボリー」方向は維持しつつ、簡素化しすぎた5箇所だけを調整した。

1. **パラメーターゲージ**（6能力：ライフ・ちから・かしこさ・命中・回避・丈夫さの横棒）
   高さ 2.2rem → 3.8rem（約1.7倍）。単純べた塗り → 能力色のグラデーション＋上部の艶＋先端の小さな光。数値も一段大きく。外枠は焦げ茶＋真鍮のまま、太い金枠には戻していない。
2. **能力値ゲージ／能力分析図**（パラメーターゲージとは別のUI。6角形のレーダーチャート）
   単色の薄茶ポリゴン → 鮮やかな青のグラデーション＋グローで主役に。金属の目盛り環や魔法陣には戻していない。
   ※この2つの名称・役割の混同がないよう、UI部品集の項目20・21の見出し文言でも明示的に区別した。
3. **ファーム5コマンド**（ボード・修行・ステータス・技管理・アイテム）
   軽い六角バッジ＋アイコン中心 → 横長プレート＋テキスト主役＋小さな丸アイコン＋シェブロン。5つ並べた時に「操作メニュー」としてひとまとまりに見える形に変更。
4. **モンスター図鑑／選択・ロックと未発見**
   ロック（条件未達成）と未発見（まだ記録されていない）を色調と装飾で区別：ロックは紋様なしの落ち着いた単色、未発見は淡い図鑑紋様＋やわらかな霧。以前の「白い四角＋？」だけの表示はやめた。
5. **技カードの紙色**
   紙をより白に近いアイボリー専用の背景（`--surface-paper-bright`）に変更。技イラストと分類色のタグが映えるように。構造は変更していない。

**修正中に見つけたバグ**：モンスター選択枠（`.mm-mslot__name`）の名前テキストが、実際には画像の外（紙の背景上）に配置されているにもかかわらず、画像に重ねる用の白文字＋縁取りスタイルのままになっており、背景色によっては読みにくかった。焦げ茶／薄茶（ロック・未発見時）の通常の文字色に修正した。
