# 牧場（ぽかぽか牧場）の背景

| ファイル | 内容 |
|---|---|
| ranch_main.jpg | 牧場画面の背景（**正式**。1152×2048・JPEG 品質88、約0.73MB）。下の元データを、寸法はそのまま・見た目を変えずに圧縮したもの（色の加工・描き直しなし） |
| original/ranch_main_official_1152x2048.jpg | 正式背景の元データ（ユーザー提供・無加工、約2.3MB）。ゲームからは参照しない |

- 正式背景には、旧仕様の人物（老人）・旧い吹き出し・旧ロゴ（旧ゲーム名）は描かれていない。人物・文字・吹き出し・モンスターは背景に描き込まず、ゲーム側で重ねる（ニックの顔・名前・一言、システム通知、連れているモンスター）。
- 参照は index.html の `const RANCH_BG="assets/ranch/ranch_main.jpg";` の1か所だけ（`farm()` の `.fscene`）。
- 画面では、牧場の枠（`.fscene`。縦横比 941:1055）に `cover` で敷き、縦の位置は `center 22%`（牧舎の屋根から入口の門までが入る）。背景を差し替えるときは、この位置も合わせる。
- 差し替え前の旧背景は `assets/embedded/farmimg_ranch.jpg`（index.html の base64 から外部化した元データ。`FARMIMG`）。互換のため残しているが、表示には使わない。旧背景に戻すときは `farm()` の `RANCH_BG` を `FARMIMG` に戻す（吹き出しの位置も旧い吹き出しの上へ戻す必要がある）。
