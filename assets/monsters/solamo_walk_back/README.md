# ソラモ 後ろ向き歩行 8コマ（2026-10-02）

出どころ：ユーザー提供の ZIP `solamo_walk_back_8frames.zip`（solamo_walk_back_01.png〜08.png、各 360×360・RGBA。元画像の上段左→右、下段左→右の順に分割したもの）。元の PNG は上書きしていない（ユーザーが保管）。

## 加工

- 元の PNG はすでに透過（周囲は不透明度0）。ただし白背景から切り抜かれていたため、輪郭の半透明の画素に白がにじんでいた（暗い背景で白い縁に見える）。
- 不透明度（毛先・耳・尻尾の形）はそのまま変えず、輪郭の半透明の画素の色だけを直した：不透明度が高い画素は白を引いて色を戻し、低い画素は最も近い不透明な画素の色にした。
- 8コマを同じ範囲で切り抜いた（元の 360×360 のうち x 24〜327・y 25〜345 → 303×320）。コマごとの位置合わせは元のまま（その場歩行。体の揺れは元の絵どおり ±2〜3px）。
- WebP（品質92・透過あり）。

## 使い方

js/chapter/configs/ch1a.js の `monsterSprites.solamo.walk`（frames 01→08・fps 12・停止の絵 idle 0＝01・noFlip）。画面は js/chapter/field-view.js（移動の間だけループ、止まると 01）。
