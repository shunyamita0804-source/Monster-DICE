# カレン（市場担当NPC）の正式素材

- アップ画像（closeup）のみで運用します。全身（fullbody）は使いません。
- ユーザー提供のPNG（1248×1872、透過なし）は、背景の市松模様が絵として描き込まれていました。その市松模様だけを透明にした透過PNG（RGBA）です。
  - 縁につながる無彩色の部分と、腕と体の間などに囲まれた市松模様の部分を透明にしました。
  - 人物の色は変えていません。CSS の filter なども使いません。
- 会話での表示の最大高さ（380px）の2倍、高さ760pxに縦横比を保って縮小しています（507×760）。元画像はユーザーが別に保管しています。
- 表情名は、元のファイル名に表情が無かったため、絵の内容から決めています（要確認。変更は js/npc/npc.js の登録とこのファイルだけで行えます）。
