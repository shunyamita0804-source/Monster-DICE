# セドリック（公式ランク大会の進行役NPC）の正式素材

- アップ画像（closeup）のみで運用します。全身（fullbody）は使いません。
- ユーザー提供の画像は JPEG（880×1168、アルファなし）6枚で、背景の市松模様が絵として描き込まれていました。その市松模様だけを透明にした透過PNG（RGBA）です。人物の色・形・髪・衣装・ヘッドセット・指示棒・手帳・手袋は変えていません。CSS の filter なども使いません。
  - 透明にしたのは、画像の縁につながる「明るい無彩色」の部分と、腕と体の間などに囲まれた部分のうち、市松の格子（1マス約12px。画像ごとに位置と大きさを測定）とほぼ一致する部分（93%以上）だけです。白い手袋も明るい無彩色ですが、格子と一致しない（35〜77%）ので残しています。
  - 髪の外側の細い線と髪の間に残る明るい無彩色の画素（背景から8px以内）は、近くの髪・服の色と市松の色との混ざり具合から透明度を決めました（手袋などの明るい部分の周りは除外）。
  - 背景に接する縁（2px）だけ、なめらかな透明度にし、混ざっていた市松の色を取り除きました（濃い背景の上で白いふちが出ないように）。それ以外の画素は元画像と同じです（完全に不透明な画素は1つも変えていません）。
- 会話での表示の最大高さ（380px）の2倍、高さ760pxに縦横比を保って縮小しています（573×760）。元画像はユーザーが別に保管しています。
- face.png：大会画面の吹き出しの小さい丸い顔用。closeup/normal の元画像（透明化後）から顔の周り（300×300）を切り出して 256×256 に縮小したものです（描き直しなし）。
- 表情名は、元の画像に表情名が無かったため、絵の内容から決めた**仮名・要確認**です（変更は js/npc/npc.js の登録とこのファイルだけで行えます）。
