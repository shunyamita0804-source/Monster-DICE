# エリオット（研究所の研究者NPC）の正式素材

- アップ画像（closeup）のみで運用します。全身（fullbody）は使いません。
- ユーザー提供の画像は JPEG（880×1168、アルファなし）6枚で、背景は無地の明るい灰色（RGB 約 218・215・205、わずかなグラデーション）が絵として入っていました。その背景だけを透明にした透過PNG（RGBA）です。人物の色・形・髪・眼鏡・眼鏡のひも・衣装・石板・鞄・鍵・拡大鏡・手袋は変えていません。CSS の filter なども使いません。
  - 画像の上・左・右の縁から背景の色のなめらかな面（2次式）を求め、その色との差が 9 以下で縁につながる部分と、眼鏡のひもと首の間・鞄のひもと体の間・髪のすき間などに囲まれた部分のうち、背景の色とほぼ同じもの（平均の差 5.5 以下）だけを透明にしました。クリーム色のシャツは背景の色と差があるので残っています。
  - 背景に接する縁（2px）だけ、なめらかな透明度にし、混ざっていた背景の色を取り除きました（濃い背景の上で白いふちが出ないように）。それ以外の画素は元画像と同じです（完全に不透明な画素は1つも変えていません）。
- 会話での表示の最大高さ（380px）の2倍、高さ760pxに縦横比を保って縮小しています（573×760）。元画像はユーザーが別に保管しています。
- face.png：研究所の吹き出しの小さい丸い顔用。closeup/normal の元画像（透明化後）から顔の周り（300×300）を切り出して 256×256 に縮小したものです（描き直しなし）。
- 表情名は、元の画像に表情名が無かったため、**画像内容から決めた仮名・要確認**です（変更は js/npc/npc.js の登録とこのファイルだけで行えます）。
