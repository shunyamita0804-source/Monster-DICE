# ゲンシン（特訓の指導役NPC）の正式素材

> 2026-09-30：ゲームで使う画像を、画素を1つも変えずに**可逆WebP（.webp、透過あり）**へ変換しました（透過PNGより約39%小さい。見た目は同じ）。下の説明の「透過PNG」は変換前の形式、表の容量（KB）がある場合は変換前の値です。

- 5種類すべての特訓（ちから・かしこさ・命中・回避・丈夫さ）を1人で担当する指導役。アップ画像（closeup）のみで運用します。全身（fullbody）は使いません。
- ユーザー提供の画像は JPEG（880×1168、アルファなし）6枚で、背景の市松模様が絵として描き込まれていました（4枚目だけ濃い灰色の市松）。その市松模様だけを透明にした透過PNG（RGBA）です。人物の顔・髪・ひげ・衣装・胸当て・ベルト・巻物・革袋・色は変えていません。CSS の filter なども使いません。
  - 市松の2色の明るさとマスの大きさ（約9〜14px）・位置を画像ごとに測り、画像の縁につながる部分と、囲まれた部分のうち市松の格子と一致するもの（明るいマス・暗いマスの両方を含む）、または市松の平らな2色だけでできたものを透明にしました。銀色の髪の白いハイライトは、1色だけで格子とも一致しないので残しています。
  - 濃い灰色の市松（4枚目）は、マスの境目（JPEG でにじんだ中間の灰色）のうち、線の両側が背景のものだけを透明にしました（髪の毛が線をまたぐところは残る）。
  - 背景に接する縁（2px）だけ、なめらかな透明度にし、混ざっていた市松の色を取り除きました。それ以外の画素は元画像と同じです（完全に不透明な画素は1つも変えていません）。
- 会話での表示の最大高さ（380px）の2倍、高さ760pxに縦横比を保って縮小しています（573×760）。元画像はユーザーが別に保管しています。
- face.webp：小さい丸い顔用。closeup/normal の元画像（透明化後）から顔の周り（300×300）を切り出して 256×256 に縮小したものです（描き直しなし）。
- 表情名は、元の画像に表情名が無かったため、**画像内容から決めた仮名・要確認**です（変更は js/npc/npc.js の登録とこのファイルだけで行えます）。
