# ヴァルガス（闘技場の管理者NPC）の正式素材

> 2026-09-30：ゲームで使う画像を、画素を1つも変えずに**可逆WebP（.webp、透過あり）**へ変換しました（透過PNGより約39%小さい。見た目は同じ）。下の説明の「透過PNG」は変換前の形式、表の容量（KB）がある場合は変換前の値です。

- アップ画像（closeup）のみで運用します。全身（fullbody）は使いません。
- ユーザー提供の画像は JPEG（1328×1760、アルファなし）6枚で、背景の市松模様が絵として描き込まれていました。その市松模様だけを透明にした透過PNG（RGBA）です。人物の色・形・髪・白髪まじりのこめかみ・傷・鎧（肩当て）・マント・房飾り・鎖・紋章・ベルト・鍵・手袋は変えていません。CSS の filter なども使いません。
  - 透明にしたのは、画像の縁につながる「明るい無彩色」の部分と、囲まれた部分のうち市松の格子（1マス約18〜20px。画像ごとに位置と大きさを測定）と一致する部分（93%以上）だけです。肩当ての銀色のハイライトは明るい無彩色でも格子と一致しない（0.8台以下）ので残しています。
  - 背景から8px以内に残る、市松と暗い前景（髪・マントなど）が混ざった明るい無彩色の画素は、混ざり具合から透明度を決めました（明るい部分の周りは除外）。
  - 背景に接する縁（2px）だけ、なめらかな透明度にし、混ざっていた市松の色を取り除きました（濃い背景の上で白いふちが出ないように）。それ以外の画素は元画像と同じです（完全に不透明な画素は1つも変えていません）。
- 会話での表示の最大高さ（380px）の2倍、高さ760pxに縦横比を保って縮小しています（573×760）。元画像はユーザーが別に保管しています。
- face.webp：小さい丸い顔用。closeup/normal の元画像（透明化後）から顔の周り（480×480）を切り出して 256×256 に縮小したものです（描き直しなし）。
- 表情名は、元の画像に表情名が無かったため、**画像内容から決めた仮名・要確認**です（変更は js/npc/npc.js の登録とこのファイルだけで行えます）。
