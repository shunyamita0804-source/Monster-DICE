# ニック（牧場の管理者NPC）の正式素材

- アップ画像（closeup）のみで運用します。全身（fullbody）は使いません。
- ユーザー提供の画像は JPEG（1328×1760、アルファなし）で、背景の市松模様が絵として描き込まれていました。その市松模様だけを透明にした透過PNG（RGBA）です。人物の色・形・髪・ひげ・衣装・小物は変えていません。CSS の filter なども使いません。
  - 透明にしたのは、画像の縁につながる「明るい無彩色」の部分（市松の2色 254・225 付近とその境目）と、髪の間・腕と体の間などに囲まれた部分のうち、市松の2色を両方含む部分だけです（髪の銀色のハイライトは明るい側の色がほとんど無いので残ります）。
  - 背景に接する縁（2px）だけ、なめらかな透明度にし、混ざっていた市松の色を取り除きました（濃い背景の上で白いふちが出ないように）。内側の画素は変えていません。
- 会話での表示の最大高さ（380px）の2倍、高さ760pxに縦横比を保って縮小しています（573×760）。元画像はユーザーが別に保管しています。
- face.png：牧場の吹き出しの小さい丸い顔用。closeup/normal の元画像（透明化後）から顔の周り（480×480）を切り出して 256×256 に縮小したものです（描き直しなし）。
- 表情名は、元のファイル名に表情が無かったため、絵の内容から決めています（要確認。変更は js/npc/npc.js の登録とこのファイルだけで行えます）。
