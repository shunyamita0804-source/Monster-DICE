# ダン（ファーム担当NPC）の正式素材

- アップ画像（closeup）のみで運用します。全身（fullbody）は使いません。
- ユーザー提供のPNG（880×1168、背景透過済み）をそのまま使っています。人物の色・形・小物は変えていません。CSS の filter なども使いません。
  - 半透明の縁（髪の毛先など）に残っていた背景の緑色だけを取り除きました（透明に近い縁の画素で、緑が赤・青より強い分を抑えただけ。内側の画素は変えていません）。
- 会話での表示の最大高さ（380px）の2倍、高さ760pxに縦横比を保って縮小しています（573×760）。元画像はユーザーが別に保管しています。
- face.png：ファームの吹き出し・Chapter間ファーム・メッセージ欄の小さい丸い顔用。closeup/normal の元画像から顔の周り（290×290）を切り出して 256×256 に縮小したものです（描き直しなし）。
- 表情名は、元のファイル名に表情が無かったため、絵の内容から決めています（要確認。変更は js/npc/npc.js の登録とこのファイルだけで行えます）。

| closeup/normal.png | 1枚目 | 落ち着いた表情（正面） |
| closeup/smile.png | 2枚目 | 穏やかな微笑み |
