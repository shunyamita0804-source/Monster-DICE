## 透過化（ユーザー承認 2026-10-03）

元ファイルはすべて JPEG（アルファなし）で、透明の代わりに市松模様（白 約253／灰 約205〜235。マスの大きさ・位置は画像の中でも一定でない）が焼き込まれていた。絵は描き直さず、背景だけを次の手順で取り除いた：

1. 明るい無彩色の画素を市松の白／灰に分け、ほかの画素には近くの市松の色を広げて、画素ごとの背景色を作る
2. 背景色との差から透明度を出し、色は背景を引いて元に戻す（無彩色は JPEG のにじみを残さないよう、しきい値を高く）
3. 白く光る中心（白い市松と同じ明るさ）は、市松の灰色のマスから1マス以上離れていれば本体として不透明に戻す
4. 色が主体の素材（#7・#15〜#20・#28）は、明るい無彩色をすべて背景として透明にした（市松の灰色の違いを残さない）
5. 正方形は 640×640、横長は 768×432 に縮小 → WebP（品質84・透過あり）

濃い背景（バトルの紫）・明るい背景の両方で目で確認した。白・灰色の煙や風（#6 の煙・#9・#29）は、白い市松と色の差が無い部分が少し薄く・粗くなっている（自動の除去の限界。透過 PNG の元データが届けば差し替えるだけ）。
