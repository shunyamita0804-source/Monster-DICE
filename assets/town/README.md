# 街の背景

| ファイル | 内容 |
|---|---|
| town_main.jpg | 街画面の背景（仮の正式候補。768×1376・JPEG）。ユーザー提供画像を無加工で配置 |

- 参照は index.html の `const TOWN_BG="assets/town/town_main.jpg";` の1か所だけ。
- 高品質版に差し替えるときは、このファイルを同じ名前で置き換えるだけでよい。
- 画面では、街の枠（縦横比 3:4）に `cover`・上寄せで敷く。画像の寸法には依存しない。
- 位置を変えたいときは、CSS 変数 `--town-pos`（既定 `center top`）で調整する。
- この仮画像は、下部（約77%より下）に仮のUI（ブリーダーの札・吹き出し）が描き込まれている。
  - 上寄せで敷くため、390×844 などの縦長の画面では、その部分は枠の外になって表示されない。
- 施設コマンド（市場・牧場・研究所・闘技場・ファーム）は画像に描かれた建物の位置に依存しない。
  - HTML のボタンとして右側にまとめている（`TOWN_CMDS`）。
