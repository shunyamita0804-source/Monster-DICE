# 街の背景

| ファイル | 内容 |
|---|---|
| town_main.jpg | 街画面の背景（**正式**。1152×2048・JPEG 品質84、約0.86MB）。下の元データを、寸法はそのまま・見た目を変えずに圧縮したもの（色の加工なし） |
| original/town_main_official_1152x2048.jpg | 正式背景の元データ（ユーザー提供・無加工、約3.0MB）。ゲームからは参照しない |
| previous/town_main_v1.jpg | 差し替える前の旧背景（仮の正式候補、768×1376）。復旧用。ゲームからは参照しない |

- 参照は index.html の `const TOWN_BG="assets/town/town_main.jpg";` の1か所だけ。
- 画面では、街の枠（画面いっぱい：幅いっぱい×高さ 100dvh）に `cover`・上寄せで敷く。縦長の画面では左右が少し切れる（390×844 で左右約42pxずつ）。
- 背景の上の建物ラベル（市場・牧場・研究所・闘技場）の位置は、index.html の `TOWN_LABELS` に**この画像上の画素（x, y）**で書いている（ラベルの下の印が指す場所）。背景を差し替えるときは、建物の位置に合わせて `TOWN_LABELS` も直す。
  - 闘技場 (578, 540)・研究所 (300, 1010)・牧場 (770, 930)・市場 (400, 1650)
- 旧背景に戻すとき：`previous/town_main_v1.jpg` を `town_main.jpg` として置き換え、`TOWN_LABELS` を旧背景の建物の位置に合わせる（または空にする）。
- 施設コマンド（市場・牧場・研究所・闘技場・ファームへ）は、HTML のボタンとして右下にまとめている（`TOWN_CMDS`）。背景に描かれた建物の位置には依存しない。
